# llmff v1.0.0 Dependency And Security Review

This is the dependency and security review record for the final `v1.0.0`
release candidate.

## Duplicate Dependency Review

Command:

```bash
cargo tree -d
```

Result:

- exit code: `0`
- duplicate major dependency families are expected from direct `reqwest 0.12`
  usage plus transitive `jsonschema 0.17` usage of `reqwest 0.11`;
- duplicate `http`, `http-body`, `hyper`, `h2`, `base64`, `socket2`,
  `sync_wrapper`, and `getrandom` instances are all explained by the same
  transitive split or by dev-only `wiremock`/`tempfile` dependencies;
- no duplicate dependency was identified as a release blocker for `v1.0.0`.

## Trust Boundary Review

- Plugin execution remains explicitly outside a sandbox and is documented as a
  local trust boundary, not as arbitrary-code security isolation.
- Provider support tiers remain evidence-backed. No provider is live-smoke
  verified unless a real smoke result is recorded.
- Windows and macOS artifacts remain unsigned; signing and notarization are
  deferred paid distribution tracks and are not claimed for this release.
- Package-manager publication remains parked until maintainers mark a channel
  support-ready and pin immutable release asset hashes.
