# Trace CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `llmff trace <path>` for compact, safe trace summaries.

**Architecture:** Keep trace presentation in the CLI layer. Parse JSONL into `serde_json::Value`, summarize only known safe metadata fields, and avoid exposing raw payload fields.

**Tech Stack:** Rust, clap, serde_json, assert_cmd.

---

- Modify `crates/llmff-cli/Cargo.toml` to add `serde_json` as a normal dependency.
- Modify `crates/llmff-cli/src/commands.rs` to add the `Trace` command and summary helpers.
- Modify `crates/llmff-cli/tests/cli_run.rs` for CLI behavior.
