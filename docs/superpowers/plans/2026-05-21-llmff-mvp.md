# llmff MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first production-shaped `llmff` MVP: a Rust CLI and library that parses pipeline manifests, validates and executes typed stages against mock/OpenAI-compatible backends, validates and repairs JSON, writes traces, and supports stdin/stdout workflows.

**Architecture:** Use a Rust workspace with `llmff-core` for graph, stage, backend, execution, and trace contracts, plus `llmff-cli` for command parsing and terminal I/O. Keep all pipeline semantics in the core crate; the CLI is a thin adapter. Implement every behavior test-first with deterministic unit and integration tests before production code.

**Tech Stack:** Rust 2021, `clap`, `serde`, `serde_json`, `serde_yaml`, `thiserror`, `anyhow`, `tokio`, `async-trait`, `reqwest`, `jsonschema`, `tempfile`, `assert_cmd`, `predicates`, `wiremock`.

---

## Rules For Every Task

- No production code before a failing test.
- Watch each new test fail for the expected reason before implementation.
- Write only enough production code to pass the current failing test.
- Run the task-specific test after implementation.
- Run `cargo fmt --all` before each commit.
- Commit each completed task independently.
- Do not add runtime networking to default tests; use mocks or `wiremock`.
- Do not store secrets in fixtures, manifests, traces, or command output.

```rust
use std::collections::BTreeSet;

use crate::error::LlmffError;
use crate::manifest::{Manifest, StageSpec};

#[derive(Debug, Clone, PartialEq)]
pub struct Graph {
    stages: Vec<StageSpec>,
}

impl Graph {
    pub fn from_manifest(manifest: Manifest) -> Result<Self, LlmffError> {
        let input_ids = manifest.inputs.keys().cloned().collect::<BTreeSet<_>>();
        let mut stage_ids = BTreeSet::new();

        for stage in &manifest.graph {
            if !stage_ids.insert(stage.id.clone()) {
                return Err(LlmffError::GraphValidation(format!(
                    "duplicate stage id `{}`",
                    stage.id
                )));
            }

            if let Some(input) = &stage.input {
                if !input_ids.contains(input) {
                    return Err(LlmffError::GraphValidation(format!(
                        "unknown input reference `{input}`"
                    )));
                }
            }

            if let Some(parent) = &stage.from {
                if !stage_ids.contains(parent) {
                    return Err(LlmffError::GraphValidation(format!(
                        "unknown stage reference `{parent}`"
                    )));
                }
            }
        }

        for output in manifest.outputs.values() {
            if !stage_ids.contains(&output.from) {
                return Err(LlmffError::GraphValidation(format!(
                    "unknown output reference `{}`",
                    output.from
                )));
            }
        }

        Ok(Self {
            stages: manifest.graph,
        })
    }

    pub fn stages(&self) -> &[StageSpec] {
        &self.stages
    }
}

    use crate::manifest::Manifest;

  final:
    from: draft
    path: ./answer.json
"#,
        )
        .unwrap();
```

```rust
use std::path::Path;

use jsonschema::JSONSchema;

use crate::error::LlmffError;
use crate::manifest::StageSpec;
use crate::value::{StageStatus, Value};

pub fn execute_deterministic_stage(
    spec: &StageSpec,
    input: Option<Value>,
    _cwd: &Path,
) -> Result<StageStatus, LlmffError> {
    match spec.op.as_str() {
        "system" => Ok(StageStatus::Success(input.unwrap_or(Value::Text(String::new())))),
        "validate_json" => validate_json(spec, input),
        other => Err(LlmffError::UnknownStage(other.to_string())),
    }
}

fn validate_json(spec: &StageSpec, input: Option<Value>) -> Result<StageStatus, LlmffError> {
    let value = input.ok_or_else(|| LlmffError::StageExecution {
        stage_id: spec.id.clone(),
        message: "validate_json requires input".to_string(),
    })?;
    let schema_source = spec.schema.as_ref().ok_or_else(|| LlmffError::StageExecution {
        stage_id: spec.id.clone(),
        message: "validate_json requires schema".to_string(),
    })?;
    let schema_json: serde_json::Value = serde_json::from_str(schema_source).map_err(|error| {
        LlmffError::StageExecution {
            stage_id: spec.id.clone(),
            message: format!("invalid inline schema: {error}"),
        }
    })?;
    let instance = match &value {
        Value::Json(json) => json.clone(),
        Value::Text(text) => serde_json::from_str(text).map_err(|error| LlmffError::StageExecution {
            stage_id: spec.id.clone(),
            message: format!("input is not valid JSON: {error}"),
        })?,
    };
    let compiled = JSONSchema::compile(&schema_json).map_err(|error| LlmffError::StageExecution {
        stage_id: spec.id.clone(),
        message: format!("invalid JSON schema: {error}"),
    })?;

    match compiled.validate(&instance) {
        Ok(()) => Ok(StageStatus::Success(Value::Json(instance))),
        Err(errors) => Ok(StageStatus::Invalid {
            value,
            errors: errors.map(|error| error.to_string()).collect(),
        }),
    }
}
```

Execution rules:

- `load` reads `StageSpec.input`, resolves it through `manifest.inputs`, reads the referenced path, and stores `StageStatus::Success(Value::Text(contents))`.
- `infer` requires a successful parent value, looks up `StageSpec.model`, sends an `InferRequest`, and stores returned text.

- `repair` only calls its model when the parent status is `Invalid`; otherwise it forwards the parent status unchanged.

- Store stage statuses in `BTreeMap<String, StageStatus>` and execute in manifest order.
- Return `RunReport { final_status: RunStatus::Succeeded }` only after every declared output has been written.
