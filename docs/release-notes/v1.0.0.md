# llmff v1.0.0

This file is the guarded release-note draft for the final v1.0 release. Do not
publish `v1.0.0` until the compatibility review in `docs/release-readiness.md`
and `docs/v1-contract.md` is complete.

## Supported Install

```bash
cargo install --git https://github.com/syndicalt/llmff --tag v1.0.0 llmff
```

## Release Bar

`v1.0.0` may ship only after:

- required local and CI gates pass;
- every stable CLI, manifest, plugin, trace, event, result, and library surface
  is covered by docs, tests, schemas, or fixtures;
- package artifacts build and smoke-test on their target platforms;
- dependency and security review is complete;
- `docs/migration/pre-1.0-to-1.0.md` is complete;
- no release note, package metadata, or launch material claims sandboxing,
  signing, provider certification, package-manager publication, or live-smoke
  verification without matching evidence.

## Expected Verification

```bash
scripts/release-preflight.sh v1.0.0
scripts/smoke-install.sh --git https://github.com/syndicalt/llmff --tag v1.0.0
```
